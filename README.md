# NOVA STORE

NOVA STORE is a polished e-commerce portfolio demo built with React, TypeScript, Vite, and Lucide icons.

## Features

- Responsive premium fashion storefront
- Product search, filtering, sorting, and detail pages
- Persistent cart and wishlist using localStorage
- Promo code demo: `NOVA10`
- Simulated checkout and order confirmation
- Mobile navigation and responsive layouts

## Development

```bash
npm install
npm run dev
```

This is a portfolio demonstration. Checkout uses simulated payment only and does not process real transactions.
